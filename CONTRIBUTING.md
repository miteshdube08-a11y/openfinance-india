
# Contributing to OpenFinance India

Thank you for your interest in contributing to OpenFinance India!

We welcome genuine contributions that improve the quality, accuracy, accessibility, and usefulness of this project.

## 1. Ways to Contribute

You can help by:

- Improving documentation.
- Correcting factual errors.
- Adding financial terminology and explanations.
- Reporting bugs.
- Writing Python utilities.
- Adding automated tests.
- Improving existing examples.
- Suggesting useful features.

## 2. Before You Start

1. Check existing issues.
2. Search for duplicate suggestions.
3. Read the project documentation.
4. For substantial changes, open an issue to discuss your proposal first.

## 3. Contribution Process

1. Fork this repository.
2. Clone your fork.
3. Create a separate branch for your changes.
4. Make your improvements.
5. Check your work for accuracy.
6. Submit a pull request with a clear explanation.

## 4. Pull Request Guidelines

Every pull request should:

- Have a descriptive title.
- Explain what was changed.
- Explain why the change is useful.
- Include relevant references for financial facts.
- Avoid unrelated changes.
- Include tests when applicable.

## 5. Financial Accuracy

Financial information must be handled carefully.

- Prefer reliable primary sources.
- Clearly distinguish facts from opinions.
- Include calculation assumptions.
- Avoid unsupported investment claims.
- Never present educational examples as guaranteed outcomes.

## 6. Code Quality

For Python contributions:

- Write readable and maintainable code.
- Use meaningful variable and function names.
- Include appropriate documentation.
- Add tests for new functionality.
- Handle invalid inputs and errors.

## 7. Community Standards

All contributors are expected to:

- Be respectful.
- Provide constructive feedback.
- Avoid harassment and discrimination.
- Respect intellectual property.
- Submit original or properly attributed work.

## 8. Questions

If you have questions, open a GitHub issue and describe the problem clearly.

Thank you for helping improve OpenFinance India!
